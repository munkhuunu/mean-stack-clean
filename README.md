# MEAN Stack Clean Project

This is a clean and modular full-stack web application built using the MEAN stack (MongoDB, Express.js, Angular, Node.js).

## 📁 Project Structure

- `server/` - Backend code (Express.js)
- `client/` - Angular frontend source
- `node_modules/` - Node.js dependencies

## 🚀 Getting Started

### Prerequisites
- Node.js (>=18.0.0)
- MongoDB
- npm (>=9.0.0)

### Installation
```bash
npm install
cd client
npm install
```

### Running the Application
```bash
# Run both frontend and backend
npm run dev

# Or run them separately:
npm run server:dev  # Backend on port 3000
npm run client:dev  # Frontend on port 4201
```

### Building for Production
```bash
npm run build
```

## 🔑 Features

- User authentication and authorization
- JWT token-based security
- Task management system
- RESTful API
- Responsive UI with Bootstrap 5
- MongoDB database integration
- Modern Angular 17 with standalone components
